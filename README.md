# SMCOAA-ELECTION-PORTAL

Official Election Portal for St. Michael's College, Oleh Alumni Association.

Features: Fixed Membership Roll Voting, Voter Dashboard, Admin Dashboard, Election View, Super Admin, Live Election Results, Audit & Verification Dashboard, Support and Privacy Tools.

Tech: React + Vite + Firebase Firestore + Vercel Serverless APIs + Cloudinary + Tailwind CSS.

Environment: Add production credentials in **Vercel → Project → Settings → Environment Variables**. See [`.env.example`](.env.example) for variable names and [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) for setup. Do not commit real credentials. Firebase and Cloudinary can be configured later.
